# Böse Wörter

Eine PWA für Smartphones, die es erlaubt, eine Strichliste von bösen Wörter zu führen. Wenn jemand in der Familie ein solches Wort verwendet, bekommt er einen Strich. Bis zu 4 Familienmitglieder hinzufügbar. Typische unerlaubte Wörter sind "Scheiße" oder "Arsch". Wenn eine Person innerhalb von einer Woche 10 Striche hat, bekommt er/sie 1 Woche Handyverbot.
